## Fixes made after the run (in `v0.2.0`, commit `3508c62`)

1. **Auditor `sed`** (`template/.claude/hooks/guard.py`): `sed -n <first>,<last>p <file>` (print
   lines only; numbers or `$`, one or more `Np` ranges) is now allowed in the auditor's
   read-only shell; any other `sed` stays blocked. Tests in `kit_tests/test_guard.py`
   (allowed: `sed -n 245,300p docs/DATA_PROFILE.json`, `sed -n '1,5p;40,$p' f`; blocked:
   `sed -i 's/a/b/' f`, `sed -n '1w out.txt' f`, `sed -n 1,5p f > copy.txt`).
2. **Running cost summary double-counted resumed agents** (`template/.claude/hooks/log_cost.py`):
   `SubagentStop` fires once per round with cumulative totals, so `--summary` added a resumed
   agent once per round (7 rows and 10.7 M tokens for 4 agents). It now keeps the last
   record per `agent_id` (with a rounds count) and per session: 7,695,055 tokens on this run.
   The hook fires before an agent's final response is in its transcript, so its numbers stay
   running figures for `log.md`; **the paper reports `cost_report.py` for both arms**
   (8,101,740 here). Test in `kit_tests/test_cost.py`.

Both fixes are unit-tested (kit suite 189 passed, 1 skipped at release). The end-to-end run
was not repeated after them (it would cost about $8 again).
